# 0001 · Registro de decisiones de arquitectura

- Estado: aceptada · 2026-11-03

Cada decisión que cambie el stack, la arquitectura o un criterio de pruebas se registra aquí como ADR numerado (formato Nygard: contexto, decisión, consecuencias). Un ADR no se edita para revertirlo: se escribe uno nuevo que lo reemplaza.
